# Учебная библиотека для iPhone

Нативное приложение на SwiftUI. Файлы, конспекты и изменения расписания хранятся на iPhone. Минимальная версия проекта — iOS 17. Сборка настроена на Xcode 26.6 и рассчитана в том числе на твой iPhone с iOS 26.6.2.

## Как получить IPA

1. Создай пустой репозиторий на GitHub. Распакуй исходники в локальную папку. В корне должны лежать `App`, `StudyLibrary.xcodeproj` и `.github/workflows/build-ipa.yml`. Сам ZIP с исходниками загружать в репозиторий не нужно.
2. Отправь содержимое папки через Git. Если загрузишь через сайт, проверь, что файл `.github/workflows/build-ipa.yml` появился в репозитории.

   ```powershell
   git init -b main
   git add .
   git commit -m "Добавить учебную библиотеку"
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```

   Если работаешь из уже инициализированной папки проекта, пропусти `git init -b main` и используй имя текущей ветки в команде `git push`. Сборка автоматически запускается для `main` и `master`.

3. В репозитории открой **Actions → Build unsigned IPA**. Можно открыть запустившуюся сборку или запустить её вручную через **Run workflow**.
4. Когда сборка завершится, в её **Artifacts** скачай **StudyLibrary-unsigned**. Распакуй скачанный ZIP. Внутри будет **StudyLibrary-unsigned.ipa**. Этот IPA и передай своей программе подписи. [Как скачать артефакт GitHub Actions](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts)
5. Подпиши IPA своим сертификатом и подходящим provisioning profile, затем установи подписанный IPA привычным способом. Исходный Bundle ID — `com.studyorganizer.library`. Если твоему профилю нужен другой идентификатор, укажи его при подписи либо замени `PRODUCT_BUNDLE_IDENTIFIER` в настройках таргета Debug и Release перед сборкой. При обновлениях используй тот же Bundle ID и совместимый способ подписи, чтобы iOS могла обновить уже установленное приложение с его данными.

В GitHub Actions не нужны сертификат, профиль или секреты. В workflow используются [macOS 26 и Xcode 26.6](https://github.com/actions/runner-images/blob/main/images/macos/macos-26-arm64-Readme.md).

## Как пользоваться

- **Библиотека.** Выбери предмет или создай свою папку. Через **+** можно импортировать несколько файлов из «Файлов», добавить изображения из «Фото» или написать личный конспект. Когда стороннее приложение предлагает открыть документ в «Учебной библиотеке», можно выбрать папку прямо при открытии.
- **Файлы.** Нажатие открывает системный предпросмотр, если формат его поддерживает. Через **⋯** можно переименовать, переместить, удалить или выгрузить материал. Для выгрузки выбери **Поделиться / выгрузить → Сохранить в Файлы** или нужное приложение. Конспекты редактируются внутри библиотеки и выгружаются в TXT. PDF, Word, PowerPoint и другие импортированные файлы сохраняются как отдельные документы.
- **Поиск.** На главном экране ищет по названиям предметов, папок, файлов и конспектов во всей библиотеке. Внутри папки поиск ограничивается её содержимым и вложенными папками.
- **Календарь.** Открой конкретную пару, запиши, что подготовить, и прикрепи материалы. Можно отметить готовность, перенести занятие, отменить или восстановить его. Время московское. Исходное расписание действует с 23 ноября по 30 декабря 2026 включительно. Первая утренняя лекция по биологии — 25 ноября, первый ЗОЖ — 30 ноября. Запись «18 лекция» сохранена дословно.
- **Настройки.** Здесь включаются уведомления за 15, 30 или 60 минут. Они выключены по умолчанию. Приложение планирует до 64 ближайших напоминаний и пополняет очередь при открытии. Здесь же можно выгрузить всю библиотеку одним ZIP и восстановить её из архива приложения. При восстановлении архив заменяет текущие файлы, конспекты и изменения календаря после подтверждения.
